# C 규칙 점검표 (2026-11-10)

작성: C. 받는 사람: A, B, D (파트별 규칙 검토용, B `src/recommend/rule_review_2026-11-06.md`와 같은 형식).

10-29 이후 C(`src/rag/`) 검색 규칙은 가상 차트 28건의 C 정답(`expected/guideline.json`)을 보고 늘었다.
A가 짚은 과적합("28개 정답에 맞추는 규칙") 걱정이 C 규칙에도 해당하는지 다시 나눠 봤다.

## 1. 판정 기준

| 표시 | 뜻 |
|---|---|
| ✅ 원칙 | ESMO 원문의 대상·조건 표현이나 확정값(의사 확인)으로 설명된다. 처음 보는 환자에게도 맞는다 |
| ⚠ 좁음 | 원칙은 맞지만 문장 한두 개를 그대로 옮긴 표현이라 범위가 좁다 (ESMO 개정 때 다시 봐야 함) |
| ❗ 조심 | ESMO 문장의 뜻보다 정답에 맞춘 느낌이 강하다 → 이번에 고침 |

점검 방법은 세 가지다.
- 각 규칙이 ESMO 청크 몇 개에 걸리는지 세고, 걸리는 청크를 모두 읽었다. 정답 사례 밖의 청크가 엉뚱하게 깎이는지 확인했다.
- 28건 정답과 따로, 평가 문제집 29문항(10-20, 가상 차트보다 먼저 만듦)의 정답도 규칙에 걸리지 않는지 확인했다. 이 확인은 시험(`test_rules_never_penalize_an_eval_set_answer`)으로 넣었다.
- 보류 세트(VC-0130~0144)는 C 정답이 없고, 보지 않았다.

## 4. 이번에 바꾼 것 (2026-11-10)

- 뺌: `DFI_REQUIRED`(de novo 감점), `NEEDS_PRIOR_CHEMO`의 'beyond third-line treatment'.
- 넓힘: 선행 결정 감점에 잔존암 권고(`RESIDUAL`), `HIGH_RISK_ONLY`의 문장 끝 표현.
- 시험: 평가 문제집 29문항의 정답이 감점 규칙에 걸리지 않는지 확인하는 시험을 더함 (28건만 보던 시험의 보완).
- 영향 (PC check_case 2026-11-10): 재투여 권고 `luminal-3l-ae383b`가 VC-0113·0125에서 2위, VC-0114에서 4위로 다시 들어왔다. 정답 파일은 그대로 오답(not_expected)이다. 다섯 사례(VC-0113·0114·0125·0121·0124) 모두 첫 정답은 1위 그대로이고, VC-0125의 `b023e3`는 4위에서 5위로 내려갔다.
- 평가 문제집 29문항 (2026-11-10): L0·L1·hit@5 100%, recall@5 0.93, MRR 0.98. 규칙을 빼고 넓힌 뒤에도 떨어지지 않았다.

## 5. 정한 것 (2026-11-11, C 제안대로 진행)

1. **ae383b는 '판단에 맡김':** VC-0113·0114·0125 정답 파일의 오답 목록에서 뺐다. 정답에도 넣지 않는다. 확정값 차수가 `>=3L`이라 3차인지 그 이상인지 가를 수 없고, 세 환자 모두 이전에 anthracycline·taxane을 썼다.
2. **C 규칙 추가는 여기서 멈춘다.** 새 감점·검색 규칙은 다음 셋을 모두 만족할 때만 넣는다.
   - ESMO 원문의 대상·조건 표현이 근거다.
   - 두 사례 이상에 적용된다.
   - 28건 정답과 평가 문제집 29문항 정답을 깎지 않는다 (`test_rules_never_penalize_*`).
   - 남은 틀린 사례는 발표·보고서에 한계로 적는다.
3. **국소 재발 고식은 범위 밖:** 원격 전이가 없고 `recurrence_type`이 `locoregional_other`(재발 부위 수술 안 함, 수술 전·수술 예정, 또는 고식 목적. 수술 전·예정은 A #150 2026-11-12)면, `retrieve_for_recommend`가 지침·급여를 넘기지 않는다 (`out_of_scope_reason`).
   - B 후처리는 지침이 없으면 이미 `out_of_scope`로 처리한다.
   - 공용 스키마(`setting.phase` palliative)를 기다리지 않고, 이미 있는 확정값으로 가른다.
   - 수술 불가 3기는 지금처럼 EBC 선행 권고를 찾는다.
   - 급여는 공고 '재발성' 고식 행이라, 지금 급여 검색(병기·보조 차수)으로는 맞는 행을 고를 수 없어 함께 비운다. 맞는 행을 찾는 방법은 D·B와 따로 정한다.
4. **tucatinib(`her2-2l-081a81`, VC-0111·0112)은 v0.1 한계로 둔다.** 같은 사례의 T-DXd 정답은 검색된다.
   - v0.2 후보: 색인할 때 소단원 제목을 청크 앞에 붙인다 (예: "HER2-positive MBC, second line: …"). 짧은 "also recommended" 문장 전체가 좋아지지만, 색인을 다시 만들어야 하고 모든 검색에 영향이 있다.
5. **⚠ 규칙:** ESMO가 개정되면(`superseded_by`) 문장을 그대로 옮긴 규칙(§2·§3의 ⚠)을 먼저 다시 본다.
