# 추천 질문지가 문맥을 넘어 앞부분이 잘림 (B 전달, 2026-11-02)

작성: 담당 A. 받는 사람: B (참고: C 검색의 소단원 붙이기, D 급여 청크 소단원).

화면 2(처방 추천 선택, `src/app/`)를 붙여 VC-0103을 처음부터 끝까지 돌리다 찾은 문제다.
B의 `recommend()`·`prompt.py`는 고치지 않았다. 고칠 방법과 정도는 B가 정한다.

## 1. 요약

- `llm/config.toml` `[recommend]`(qwen3:14b, `num_ctx = 16384`)로 VC-0103 추천을 돌리면 **추천이 0개**다.
  LLM이 전이성 환자에게 "수술후보조요법"을 후보로 쓰고 받지 않은 청크 ID(`2026-155`)를 인용해, 후처리가 모두 지웠다.
- 원인: **질문지가 81,998자로, 문맥 16,384토큰을 크게 넘는다.** Ollama는 넘친 질문지의 **앞부분을 버리므로**
  지시문·환자·바이오마커·지침 청크가 잘리고, 뒤쪽 급여 소단원 본문만 모델에 들어간다.
- 가장 큰 부분은 **급여 청크마다 붙는 소단원 본문**이다. 서로 다른 소단원은 4개인데 17번 반복해 붙어 56,917자를 차지한다.
- 급여 소단원 본문을 빼고 다시 돌리면 질문지가 11,584토큰이 되고, **fulvestrant + palbociclib**(ESMO MBC 1차, 3다 연번 7 행)이 맞게 나온다.

## 4. 줄였을 때 토큰 수 (같은 질문지에서 소단원만 바꿈)

| 질문지 | 글자 | 토큰 | `num_ctx` 16,384 안에 드나 (답 `max_tokens` 4,096 포함) |
|---|---|---|---|
| 지금 그대로 | 81,998 | 약 4만 5천 이상 (앞 절반만 23,567) | 아니오. qwen3:14b 최대 문맥 40,960도 넘음 |
| 같은 소단원은 한 번만 | 33,250 | 18,468 | 아니오 |
| 급여 소단원 모두 뺌 | 25,098 | 11,584 | 예 (15,680) |
| 둘 다 | 22,582 | 10,839 | 예 (14,935) |

`num_ctx`는 질문지와 답을 합한 길이다. 답 4,096토큰을 남기려면 질문지가 약 12,000토큰 아래여야 한다.
**`num_ctx`만 늘려서는 풀리지 않는다** (지금 질문지는 모델 최대 문맥보다 길다).

## 6. B가 정할 것 (A 제안)

1. 질문지 길이 제한: 급여 소단원은 넣지 않거나, 같은 소단원은 한 번만 + 앞부분만. 지침 소단원도 같은 것은 한 번만
2. `build_prompt` 뒤에 길이를 재서 `num_ctx - max_tokens`를 넘으면 경고하거나 청크 수를 줄이기 (잘린 채로 조용히 돌지 않게)
3. 후보를 여러 개 쓰도록 지시 (지침 청크에 나열된 요법마다 하나씩)
4. `evidence`·`drugs`: 출력 형식에 있는데 비어 온다. 지시를 세게 하거나, 후처리가 인용한 지침 청크의 근거 수준·약 목록에서 채우기
