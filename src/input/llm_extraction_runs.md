# 입력 모듈 LLM 추출 시험 기록 (1차 → 2차 → 3차)

> 담당 A · 2026-10-23 ~ 2026-10-26 · 모델 `hf.co/mradermacher/hari-q3-8b-GGUF:Q4_K_M` (`llm/config.toml` `[extract]`, 온도 0, 생각 모드 끔) · CPU

가상 차트 10건(VC-0101 ~ VC-0109, VC-0106b)을 로컬 LLM으로 끝까지 돌려 정답 `patient_state`와 칸 단위로 비교했다.
차수마다 무엇을 고쳤고 점수가 어떻게 바뀌었는지 적는다.

## 0. 시험 방법

### 처리 흐름

LLM은 값을 계산하지 않고 "어느 칸의 값이 원문 어디에 적혀 있나"만 답한다. 나머지는 규칙 코드가 한다 (`script/pipeline/`).

| 단계 | 하는 일 | 파일 |
|---|---|---|
| ① LLM (IN-2) | 문서마다 칸 목록(출력 스키마 enum)과 예문 1개를 주면 `{field, quote, specimen, observed_date}` 후보를 JSON으로 낸다 | `extract.py` |
| ② 인용 확인 | 가림 표시를 되돌린 뒤 원문에서 구절을 찾아 위치를 계산한다. 없으면 버린다 | `quote.py` |
| ③ 정규화 (IN-3) | 구절 → 표준값 (사전·정규식) | `normalize.py` |
| ④ 조립 (IN-4~7) | 값 고르기, 충돌, 기록 없음, 투약 setting, 차수, 스키마 검사 | `assemble.py` |
| ⑤ 채점 | 정답과 칸마다 status·값 비교 (원문 표기 `raw` 제외, 위치는 따로) | `script/evaluation/score.py` |

LLM을 붙이기 전에 ① 자리에 정답에서 뽑은 후보를 넣어 ②~⑤가 29건(10건 + 짝 사례 19건) 모두 100%가 되게 맞췄다.
그래서 LLM을 붙인 뒤 생긴 차이는 LLM 출력에서 온 것이다.

### 지표

| 지표 | 뜻 |
|---|---|
| 필드 정확도 | 맞은 칸 / 전체 칸. 한쪽에만 있는 칸은 다른 쪽을 `not_recorded`로 본다 |
| 정답 present 칸만 | 정답에 값이 있는 칸만 센 정확도 (`not_recorded` 칸이 많아 전체 정확도가 높게 보이는 것을 막는다) |
| 근거 위치 | 정답 인용 위치와 똑같은 비율 / 평균 겹침 비율 |
| 인용 준수율 | 원문에서 찾은 구절 / LLM이 낸 구절 |

### 실행

```bash
python -m src.input.script.pipeline --out data/input/runs/<이름>     # LLM으로 10건 (CPU 약 55분)
python -m src.input.script.pipeline --replay data/input/runs/<이름>  # 저장한 LLM 후보로 규칙만 다시 (몇 초)
python -m src.input.script.evaluation data/input/runs/<이름>           # 채점
```

결과 폴더(`data/input/runs/`, git 제외): `hari-q3-8b-v1`, `-v2`, `-v2r`, `-v3`, `-v3r`

- 2차의 LLM 출력은 1차와 같다 (프롬프트 그대로, 온도 0). 후보 수 차이 25개는 2차에서 버린 `"null"` 구절 수와 같다. 그래서 1 → 2차의 점수 변화는 모두 규칙 효과다
- "규칙"만 바꾼 차수(2차 + 규칙, 3차 + 규칙)는 앞 차수에 저장한 LLM 후보를 그대로 다시 조립했다

## 2. 1차 전에 고친 것 (VC-0103 문서 시험, 2026-10-23)

VC-0103 문서 6개로 먼저 시험해 나온 문제를 고치고 1차를 돌렸다.

| 문제 | 고친 것 | 파일 |
|---|---|---|
| LLM이 문서마다 나이(`F/54`)를 내서 나중 나이가 골라짐. 정답은 진단 시 나이(`F/52`) | 나이는 날짜가 가장 이른 값, 나중 나이는 이력에 남기지 않음. 같은 값·검체의 반복(성별 등)은 이력에서 뺌 | `assemble.py` |
| 전이 병소 생검 소견을 진단 시 전이 부위 칸에 넣음 | 칸 설명에 "재발·전이 병소의 생검 소견은 넣지 않는다" | `extract.py` |
| `폐경 후`를 폐경 근거 칸에 넣으면 기본값 `age_amenorrhea`가 생김 | 근거 단어(LMP·몇 세 폐경·월경 등)가 있을 때만 값 | `normalize.py` |
| 경과기록의 `pT2N0M0`를 임상 TNM 칸에 넣음 | TNM 접두어(c / p / yp)가 칸과 다르면 받지 않음 | `normalize.py` |
| 흉부 CT의 폐 결절 크기를 유방 종괴 크기로 넣음 | 유방·종괴 단어가 있을 때만 받음 | `normalize.py` |

## 3. 1차 → 2차: 규칙 보강 (LLM 출력은 같음)

1차 틀린 39칸 중 23칸이 LLM이 칸을 잘못 고른 구절이었다. 규칙으로 막아 39 → 16칸.

### 정규화 방어 (`normalize.py`): 15칸

| 규칙 | 고쳐진 칸 | LLM이 낸 구절 |
|---|---|---|
| 유전자 칸은 구절에 그 유전자 이름이 있어야 받음 (`BRCA1/2`는 둘 다) | 9 (VC-0101·0102·0107 생식세포 BRCA1·BRCA2·PALB2) | `PIK3CA H1047R`, `palbociclib 18개월`, `재발·전이 소견 없음` |
| 칸마다 필요한 단어가 있어야 받음: 심장 과거력(심장 등), 종격동 방사선(종격동), 재발 수술(수술·절제), 국소 재발 후 원격 전이(원격). 동반 질환은 재발·전이 구절을 받지 않음 | 5 (VC-0107) | 한 구절 `재발·전이 소견 없음`을 다섯 칸에 넣음 |
| 보조 내분비 종료일은 종료·중단·완료 단어가 있어야 받음 | 1 (VC-0104) | `2023.9.4 간 전이` |

함께 넣은 방어 (이번 10건에서는 칸 수 변화 없음): 국소 재발 구절은 원격 전이일로 받지 않음, `58세 폐경 후`의 나이는 폐경 근거가 아님.

### 조립 규칙 (`assemble.py`): 8칸

| 규칙 | 고쳐진 칸 | 거른 후보 |
|---|---|---|
| 재발이 없으면 재발 부위 칸을 비움 (정답 표기, A 결정) | 4 (VC-0105·0106·0107·0108) | `재발 소견 없음`, `원격 전이 없음`, `bone only` |
| ypTNM 문서의 크기·림프절은 yptnm에만 (스키마 설명) | 2 (VC-0105) | `잔존 종양 크기: 1.4 cm`, `림프절: 1/3 (+)` |
| 진단 시 IV기면 전이일 0, 그래서 표 첫 칸이 없는 투약도 전이 setting | 2 (VC-0108) | 전이일, ribociclib + letrozole setting |

함께 넣은 규칙: 진단 시 IV기가 아니면 진단 시 전이 부위에 전이 구절을 받지 않음, 유전자 칸에는 이력을 두지 않음 (VC-0102 스키마 오류 해결).

### 실행 도구

- LLM이 빈 칸에 쓴 `"null"` 같은 구절은 후보에서 버림 → 인용 준수율 93.9% → 99.5% (원문에 없는 구절로 버려지는 것은 이제 지어낸 구절뿐)
- LLM 후보를 `candidates.json`으로 저장, `--replay`로 규칙만 다시 조립 (규칙을 고칠 때마다 1시간 실행을 하지 않아도 됨)

## 4. 2차 → 2차 + 규칙: 3칸 (다시 조립)

| 규칙 | 고쳐진 칸 | LLM이 낸 구절 |
|---|---|---|
| LLM이 `58세 폐경`까지만 잘라 옮겨도 원문에서 바로 뒤가 "후·전"이면 폐경 근거가 아님 | VC-0102 폐경 근거 | `58세 폐경` (원문 `58세 폐경 후 여성`) |
| 재발·전이 날짜 칸은 재발·전이 단어가 있어야 받음 (날짜만 있는 구절 제외) | VC-0109 원격 전이일 | `2022.9.29` (재발 병소 수술일) |
| 진단 시 IV기가 아니고 진단 시 전이 부위 후보가 없으면 TNM의 M0로 "해당 없음" | VC-0104 진단 시 전이 부위 | (후보 없음) |

이 차수에서 "없는 값을 만듦"이 0칸이 됐다. 남은 13칸 중 12칸은 LLM이 구절을 내지 않은 칸이었다.

## 5. 2차 → 3차: 프롬프트 수정 (`extract.py`)

LLM이 놓친 칸을 노려 칸 설명과 예문을 고쳤다.

| 칸 | 고친 설명 |
|---|---|
| 수술 가능 여부 | "'검체:' 줄의 수술 이름 그대로. 수술 검체일 때만, 중심 생검·침생검은 내지 않는다" |
| 재발 상태 | 예시 추가 (재발 소견 없음, 재발 아님 (진단 시 IV기)), "치료 반응(PD 등)은 넣지 않는다" |
| 보조 내분비 종료일 | "날짜가 없는 구절은 내지 않는다" |
| 재발 부위 | "원격 전이가 없다고 적혀 있으면 그 구절 (예: 원격 전이 없음)" |
| 국소 재발 후 원격 전이 | 예시 "수술 후 원격 전이 소견 없음" |
| 동반 질환 | 예시 (고혈압, 당뇨, CKD 3a), "유방암·재발·전이는 넣지 않는다" |
| 영상 판독·유방 종괴 크기 | 두 칸의 역할을 나누고, 영상 예문에 유방 종괴와 간 전이 의심을 함께 넣음 (시험 세트와 다른 문장) |
| 공통 규칙 3 | "같은 칸이 여러 번 나오면 (판독 요약과 본문 표 등) 값이 같든 다르든 모두 낸다" |

결과: 8칸 고쳐지고 7칸 새로 틀림 (13 → 12칸).

| 고쳐진 칸 (8) | 새로 틀린 칸 (7) |
|---|---|
| 수술 가능 여부 4 (VC-0101·0104·0106·0106b) | 재발 상태 2 (VC-0102·0103): `PD`, `진행`을 냄 |
| VC-0105 유방 초음파 판독, 유방 종괴 크기 | VC-0107 보조 내분비 종료일: `보조 내분비요법 상의 예정` → `not_done` |
| VC-0106b 재발 상태 | VC-0104 생식세포 BRCA1·BRCA2: `BRCA1/2`를 `BRCA1`로 바꿔 옮겨 버려짐 |
| VC-0109 국소 재발 후 원격 전이 | VC-0109 tamoxifen 줄: `놀바덱스`를 `놀바.dex`로 옮겨 버려짐 |
| | VC-0108 유방 종괴 크기: PET의 `우측 유방 2.7 cm 종괴`를 맞게 찾았는데 정답에 없음 |

재발 상태 칸에 "PD는 넣지 않는다"를 적자 오히려 PD를 내기 시작했다. 금지 문구보다 규칙으로 보완하는 편이 안정적이다.
