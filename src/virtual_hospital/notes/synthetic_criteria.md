# 가상 데이터를 넣은 기준

작성: 2026-11-12 (A) · 고침: 2026-11-18 (실제 등급, 판정 기준일, 재발 갈래) · 규칙 원본: [../rules/rules.csv](../../../data/virtual_hospital/rules/rules.csv), 숫자·출처: [../rules/references.csv](../../../data/virtual_hospital/rules/references.csv)

이 문서는 TCGA·BCNB에 **없는 값을 어떻게 만들었는지**, **실제 값을 어떻게 바꿨는지**를 한곳에 모은 것이다. 실제 값을 그대로 옮긴 칸은 README §6에 있다.

## 0. 근거 순위

합성값은 위에서부터 쓸 수 있는 첫 근거로 만든다. 같은 vp 번호면 늘 같은 값이 나온다 (vp 번호와 규칙 id로 정한 난수).

| 순위 | 근거 | 이 문서에서 쓴 예 |
|---|---|---|
| ① | 같은 환자의 다른 실제 값에서 계산 | MX → M0, % 구간 → Allred 비율 점수, 크기 → cT |
| ② | 같은 데이터셋 안의 실제 관계 (분포) | 판정만 있는 HER2 → 같은 판정 환자의 실제 점수·FISH 조합 |
| ③ | 같은 환자의 다른 실제 데이터 (대리 지표) | Ki-67 ← MKI67 RNA 발현 순위 |
| ④ | 문헌 (원문 확인한 숫자) | 판독 없는 21명의 grade, ECOG, 초음파 정확도 |
| ⑤ | 고정값 (근거 없음) | 날짜 간격, 수술 쪽, 성별 |

**공통 조건:** 합성값을 mini 처방 모듈 규칙으로 판정해도 **원래 실제 판정과 같아야** 한다. 맞는 값이 없으면 만들지 않고 환자를 뺀다.

### 3.1 숫자에 대한 주의

- **R-01 (KBCR):** Ki-67이 기록된 환자만으로 계산했다. HER2-0 군은 약 절반이 Ki-67 결측이다 (표에 결측 행 없음)
- **R-01 (HER2+ Ki-67):** 한국 전국 자료(KBCR 논문)의 Ki-67 표는 HER2 양성을 뺐기 때문에 HER2+만 일본 자료를 쓴다. R-02(grade)는 KBCR Table 1에 HER2+ 아형이 있어 세 아형 모두 KBCR
- **R-02 (grade):** 출처 표가 아형별로만 나와 있어 Ki-67 높음 여부로 나누지 않는다
- **R-03 (ECOG):** 보조 항암을 받은 환자만의 값이라 건강한 쪽으로 치우칠 수 있다. 표에 2 이상이 따로 없어 "1 이상"은 1로 쓴다. 한국 자료(KBCR 등)에서 ECOG를 찾지 못했다
- **R-04 (초음파):** 한국 단일 기관, 촉진상 림프절 음성 환자다. 메타분석(He 2026, 17개 연구)은 민감도 0.69로 더 높다. 이 연구는 촉진상 음성 환자라 민감도가 낮게 나온 것일 수 있다
- 출처를 검색으로 찾을 때 PubMed는 자동 요청을 막아 PMC 원문과 Europe PMC API로 읽었다
