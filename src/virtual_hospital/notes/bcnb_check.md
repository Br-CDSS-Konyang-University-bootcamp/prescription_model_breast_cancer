## 3. TCGA와 다른 점

- HER2 점수(`HER2 Expression`)가 전원 있다 → 점수 없는 HER2 문제(mini H3)가 없다
- pTNM이 없다 (수술 전 생검) → MX 문제(mini H1)도 없다. cT는 크기로 계산 (D-B1), cN은 초음파 정확도로 합성 (Y-B2)
- ER·PR은 양성/음성만 있어 Allred 점수는 TCGA 실제 분포로 합성 (Y-B1 + Y-06)
- 유전자 검사(NGS)가 없다 → 확정 상태의 변이 칸은 모두 기록 없음 (실제 수술 전 병원과 같음)
